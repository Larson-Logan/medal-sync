MEDAL SYNC · WINDOWS SETUP

Your recordings, on your storage.

Setup has installed the companion. Follow these steps to connect a library and choose where your clips live.

1. Check the storage dependencies

Setup includes pinned rclone beside the companion. All-users setup offers the bundled WinFsp driver when it is missing. Per-user setup needs an existing WinFsp installation or an administrator to install the driver once. Follow the getting started guide. The Medal Sync executables already include .NET.

2. Choose your storage

  • Server with SSD cache: keep your complete media collection on an SMB share and use local SSD space while recording.
  • Local storage with optional cloud copies: use --storage-mode local --remote E:\MedalLibrary. Your media and journal stay on this PC; an SMB server is not required.
  • Server and persistent local copy: add --local-copy-root E:\MedalLibrary when creating configuration. Clips are recorded locally and copied to the server before handoff. The local collection stays after the session.
  • Google Drive without a server: choose --storage-mode cloud or the wizard's Google Drive mode. Keep a persistent local recording copy and use Drive for media, library history and cross-PC ownership. Follow cloud setup to allocate one journal ID and reuse it on every PC. Initialize only the first PC; additional PCs join by launching.
  • Cloud replicas: configure OneDrive, Dropbox or Google Drive using rclone config --config C:\Private\rclone.conf, then add --cloud-remote onedrive:MedalSync --rclone-config C:\Private\rclone.conf. Cloud copies contain referenced media. Server mode keeps the shared journal on SMB; local mode keeps its journal on this PC.

Read the storage guide for complete examples and multiple cloud destinations.

3. Preview, verify, then enroll

Quit Medal normally and keep an independent media backup. Use config create to preview a candidate configuration, then config validate --config FILE. Follow the getting started guide to verify assets and initialize a new library, or enroll an additional PC into an existing one. For cloud mode, use the cloud setup guide's initialization and join steps.

Your account login, microphone settings and device identity stay on each PC.

4. Launch through Medal Sync

Open Medal Sync from the Start menu. After quitting Medal, wait for Ready before switching PCs. An interrupted upload keeps the session and local files for retry. Updates and uninstall also require Ready.

Open Medal Sync Status from the Start menu or the notification-area icon to see uploads, verification, the required replica and the last confirmed status. Unknown or stale status means keep this PC's session and cache. Retry finish is offered only for this PC's interrupted handoff. Closing the panel keeps supervision running; choose Exit Medal Sync in the panel or tray menu after Ready before running setup or uninstall. Check for updates can download and verify the installer, then close Medal Sync and open Windows setup.
